# Node.js 最佳实践

## 性能与事件循环

- **捍卫事件循环 (Don't Block the Event Loop)**：HTTP 请求路径、实时流式响应和用户关键路径不得执行同步耗时操作（如大文件同步读写、超大 JSON 解析或复杂正则计算）。启动期小文件读取、测试脚本、构建脚本或一次性本地工具可使用同步 API，但必须保持范围小且不进入用户请求热路径。
- **CPU 密集型任务隔离**：CPU 密集型任务必须移交异步 API、Worker Threads 或独立进程，避免阻塞主事件循环。

## 错误与安全

- **优雅的错误处理与崩溃重启**：严禁通过空的 `catch` 吞噬致命错误。对于内存泄漏或未捕获严重异常，最佳实践是让进程干净地崩溃 (Fail Fast)，并交由进程管理器或编排平台安全重启，防止状态污染。
- **安全防线 (Security Headers & Secrets)**：公网接口必须配置安全响应头以防御常见 Web 攻击。任何秘钥严禁硬编码在代码中，必须通过安全配置或环境变量注入。
