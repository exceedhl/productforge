# 产品战略分析 (Product Strategy Analysis)

本命令包含三个战略分析模块，可以单独使用，也可以组合使用。

`/lh strategy`

用户说竞品 / SWOT / 画布 / 定价时做对应段；只点命令则按仓库缺哪份推断，或按 **竞品 → SWOT → 精益画布** 问一次。

## 模块导航

| 模块 | 适用场景 | 关键输出 |
|---|---|---|
| **竞品分析** | 了解竞争格局、寻找差异化机会 | 竞品对比表 + 差异化定位 |
| **SWOT 分析** | 全面评估内外部环境、制定战略 | SWOT 快照 + TOWS 战略矩阵 + CEO 建议 |
| **精益画布** | 梳理商业模式、制定定价策略 | 9 宫格画布 + 定价模型 |

> 综合需求建议按 **竞品分析 → SWOT → 精益画布** 的顺序执行。
>
> **下一步**: 完成后走 `/lh prd` 做用户画像和旅程地图。

## 交互式引导 (Interactive Discovery)

在开始任何分析模块之前，如果用户没有提供足够的上下文，**必须先进行引导式提问**：

### 通用引导问题（根据模块选择适用的）
1. **产品阶段**: 你的产品目前处于什么阶段？（概念期 / MVP / 增长期 / 成熟期）
2. **目标市场**: 你的目标用户群体是谁？在哪个地理/细分市场？
3. **已知竞品**: 你已经知道哪些竞品？（直接/间接皆可）
4. **核心假设**: 你对市场的核心假设是什么？（需要验证还是已验证？）
5. **决策目标**: 这次分析要支撑什么决策？（融资 / 定位调整 / 新功能优先级）

> 收到足够信息后再执行分析。不要在信息不足时输出空泛的分析。

## 模块一：竞品分析 (Competitor Analysis)

### 核心原则
*   **广度覆盖**: 竞品不只是同行，也是用户解决同类问题的其他手段（替代方案）。
*   **维度聚焦**: 选取与核心竞争力最相关的对比维度。

### 执行步骤

#### 第一步：识别竞争对手
1.  **直接竞品 (Direct)**: 功能和定位高度重合的产品。
2.  **间接竞品 (Indirect)**: 解决相同问题但形态不同的产品。
3.  **替代方案 (Alternatives)**: 用户目前的惯性解决方案。

#### 第二步：多维度对比
创建对比表格，维度包括：产品形态、核心优势、核心劣势、审美/体验、商业模式。

#### 第三步：差异化总结 (Blue Ocean Strategy)
明确**差异化定位**：我们即将在哪个维度建立压倒性优势？

## 模块二：SWOT 分析与战略推演

> 输出模板参见 `templates/TEMPLATE_SWOT.md`。

### 思维准则
1.  **MECE Principle**: 分析要素相互独立、完全穷尽。
2.  **Evidence-Based**: 拒绝通用废话，需说明具体证据（如"3秒内响应的极致体验"）。
3.  **Prioritization**: 标记 "Game Changers" (关键变量)。
4.  **Cross-Impact**: 分析内部能力与外部环境的化学反应。

### 分析规则
- **Internal (S/W)**: 关注"相对优势"。劣势要诚实，直击痛点。
- **External (O/T)**: 关注 PESTEL 宏观趋势和微观竞争。机会必须是具体的可变现点。
- **Strategy**: 策略必须是 **Verb + Noun** 的行动指令。

### 输出结构
1. **SWOT Snapshot** — 表格 + ⭐ 标注高权重
2. **TOWS Strategic Matrix** — SO/WO/ST/WT 四象限推演
3. **CEO Summary** — 3 条最高优先级建议

## 模块三：精益商业画布与定价策略

### 核心原则
*   **商业闭环**: 清晰定义核心价值交换机制。
*   **放弃平庸**: UVP 和门槛优势必须是真正的差异化，拒绝套话。
*   **定价心理学**: 结合目标用户的心理账户。

### 执行步骤

#### 第一步：精益商业画布 (Lean Canvas)
9 宫格表格，重点模块：Problem、Solution、UVP、Unfair Advantage、Revenue Streams。

#### 第二步：定价策略 (Pricing Strategy)
*   **货币体系**: 价值载体设计。
*   **价格锚点**: 主推方案与对比逻辑。
*   **变现机制**: 核心营收 + 惊喜营收。
*   **增长黑客**: Share-to-Earn、拼团等传播机制。排除低端广告模式。
